# Vendor Matrix Compare

Side-by-side vendor and service comparison with weighted scoring and a recommendation engine. Build your own criteria matrix, score vendors, and get a defensible recommendation in minutes.

**Live app:** https://zion-support.github.io/vendor-matrix-compare/

## Features
- Custom criteria with weights (price, features, support, security, compliance)
- Side-by-side scoring matrix with automatic totals
- Recommendation engine that explains the winner
- Shareable/exportable comparison for procurement decisions
